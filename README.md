# MI Diversão — catálogo de locação de brinquedos

Catálogo online com reserva por data, sacolinha, pedido enviado pelo WhatsApp e painel para os donos.

**Demonstração:** https://fabricior13.github.io/MI-diversao/

A demonstração roda inteira no navegador: os pedidos e cadastros de teste ficam salvos só no
aparelho de quem abriu. O painel dos donos abre pelo link na faixa do topo.

Como rodar o site completo, publicar e o que cada pasta faz: veja o [LEIA-ME.md](LEIA-ME.md).
